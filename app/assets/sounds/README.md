# Bell Notification Sound

This directory should contain the bell notification sound file:
- bell-notification.mp3 (continuous bell sound for agent notifications)

For development, you can download a bell sound or use a placeholder.
The AgentNotificationScreen will handle gracefully if the sound file is missing.

Recommended sound characteristics:
- Duration: 3-5 seconds (will be looped continuously)
- Volume: Clear but not jarring
- Format: MP3 or WAV
- Quality: Good enough for mobile playback

You can find royalty-free bell sounds at:
- freesound.org
- zapsplat.com
- pixabay.com (audio section)

Once you have the sound file, place it here as 'bell-notification.mp3'
